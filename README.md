# Conlang Dictionary

A dictionary web app for my brother's constructed language — 1,500+ entries with search, filtering, and an editing interface, backed by a PostgreSQL REST API.

**Live:** [conlang-site.vercel.app](https://conlang-site.vercel.app)

## Tech Stack

- Next.js, TypeScript
- PostgreSQL (hosted on Neon)
- Tailwind CSS
